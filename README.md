## 泰深强在哪：工具是原料，组合才是能力

大多数 AI 工具在比谁的**工具清单更长**——搜索、爬虫、跑代码、开浏览器，几十个工具排开，列表很壮观。

泰深的判断不一样：**清单谁都能列，能力在组合。**

先说清楚一件事：泰深内置几十个工具，这本身没什么稀奇。真正难的是另外两件事——

**第一件，编排。** 这几十个工具，加上技能、外部服务、分身，如何被组织成一个针对你**当下这个具体问题**的能力组合。同一批原料，编排方式不同，结果天差地别。

**第二件，自造。** 当现有组合不够用时，泰深能自己写工具、自己封经验、自己长出新能力——不需要你懂代码，也不需要等开发者发版本。

这两件事，才是「AI 工作台」和「聊天客户端」真正的分野。

### 基础能力矩阵：四类能力，任意组合

这是泰深的**基础能力矩阵**——四类可自由组合的基础能力。在这之上还有更高阶的能力形态：自我工具开发、自我经验封装、会话级编排（见下文）。

| 类别 | 是什么 | 用在什么时候 |
|------|--------|-------------|
| **Skill 技能** | 一套工作模式（Markdown 工作流模板） | 改变「怎么想」——换一种思考框架 |
| **SubAgent 分身** | 独立工作的子代理，可各配不同模型 | 多个独立任务同时推进 |
| **MCP 外部服务** | 外接的工具服务（搜索 / 行情 / 代码图谱…） | 需要「外部有什么」 |
| **内置工具** | 原子操作（读写 / 执行 / 网络 / 文档…） | 动手做具体的事 |

四者不是四个平行列表，是一个矩阵——**可以任意组合、协同作战**。一次真实的任务长这样：

> 「帮我摸一遍这三家公司的底，出一份对比报告」

泰深会这样拆：

1. 激活 **deep-research 技能** —— 拿到一套「先铺证据、再下结论」的研究框架
2. 派 **三个分身** 并行 —— 一人盯一家公司，各自读年报、抓新闻、查财务
3. 调 **MCP 服务** —— anysearch 搜公开信息、firecrawl 抓官网深页、通达信取行情
4. 用 **内置工具** —— 解析 PDF 年报、抓 Excel 财务表、最后生成 Word 报告
5. 全程 **主身只做判断** —— 分身负责跑腿，结论由主身亲自下

你只说了一句话。这套编排是泰深自己生成的，不是你配的。

### 自我进化：泰深会长出自己的能力

这是泰深最不像「工具」的地方。

**自我工具开发** —— Skill 不够用时，泰深直接给自己写 TypeScript 工具。编译、注册、下次会话生效。它能调用外部 API、引入 npm 包、做特定计算——**你不需要懂编程**。

**自我经验封装** —— 每次会话结束，后台提取一组行为指纹：用了哪些工具、按什么顺序、处理了什么格式的数据、你说了哪些触发词。同一个模式反复出现，系统内部会响起一个信号：这个流程熟了，该封装了。

于是泰深会主动来找你：「这个动作我做了四次了，要不要封装成一个技能？」

**试用到固化** —— 新封装的技能先进试用期（pilot）。用着顺手、验证有效，转正固化；效果一般，安静退场。**永远不会自动固化**——固不固化，你说的话算数。

**能力会老，也会被淘汰** —— 每个封装产物的调用时间戳和频次都被记录。30 天无人使用自动禁用（不删除，防误杀），每季度提醒你清理。封装前它还会先自查一次：已有能力能不能覆盖？能不能给已有技能加个参数替代新建？

这意味着什么？**每个用户的泰深，三个月后长得都不一样。** 做学术的，长出一套文献检索技能；做内容的，长出一套平台适配流程。它跟着你的工作流一起生长。

## Commander 智能体引擎

泰深不是「问答机器人」，是能自主规划、调度工具、验证结果的 Commander 形态智能体。

**五阶段工作流** —— Plan → Todo → Execute → Verify → Done。右侧面板实时可见每一步进展。AI 自主拆解复杂任务、调度工具链、验证产出质量，你只需要确认关键决策。

**主动弹窗引导** —— 这是泰深的核心交互，不是辅助功能。不会写 Prompt？说一句「帮我分析下这几份竞品报告」就行。需求模糊？泰深弹窗问你：「对比维度你更看重功能还是定价？」「输出 Word 还是 PPT？」——直到确认你的真实意图。点一下按钮，比猜错方向重做快一百倍。用户不是 Prompt 工程师，是**委托人**。

**追根溯源诊断** —— 面对问题先诊断后开方。区分症状修复和根因修复，不拿 workaround 糊弄你。

**制度性闭环** —— 从计划到交付的完整链条：主动追问模糊需求、不确定时说明假设、完成时自我验证。

**情绪优先于任务** —— 检测到你的烦躁、疲劳或愤怒信号，任务本能立刻让位。你说「烦死了」，它停下来，不追问、不推任务。

**受阻不硬撞** —— 同一条路连续失败两次，它会自己调整路线或是退回；遇阻先停下审视：方法为什么失败、有没有别的路、现有信息够不够下结论。

## 泰案画布系统

泰深内置的流式内容工作空间——AI 在上面边写边呈现，你实时看到内容成型。

十一种画布覆盖全场景：

| 画布 | 能力 |
|------|------|
| **写作** | 逐字流式输出，边写边看边调整；选中段落即可让 AI 改 |
| **代码** | Monaco 语法高亮 + 内嵌终端，写完直接跑测试；支持并排 diff 对比 |
| **HTML** | 所见即所得预览，框选页面元素即标注，设计评审不用再截图圈画 |
| **终端** | 命令执行全程可见，随时叫停；支持信号控制与输出捕获 |
| **数据分析** | 表格 + 四种图表，拖入 CSV 直接出图；视图与图表类型可实时切换 |
| **调色** | 图层与复合蒙版、曲线、混合模式；本地模型做深度/天空/人脸/主体分割；批量调色；导出 PSD（保留调整链与蒙版） |
| **设计** | AI 原生矢量设计稿——62 项元素库 + 8 机型设备预览框 + 可加载外框库 + 我的元素；导出 PNG/SVG/JSON/HTML |
| **PPT** | 原生转场与动画 + 178 种形状 + 39 种艺术字 + 13 类图表；可直接打开现有 .pptx 改版式，导出保持原生可编辑 |
| **拼豆** | 网格绘制 + 图片转图纸（本地离线栅格化，零 token 成本）+ 色卡组 + 用量统计 |
| **股票** | 自然语言转策略 + 条件引擎 + 实时消息区 + AI 画线 + 智能盯盘 |
| **桌面** | 窗口实时预览 + 三层授权 + 六种动作（观察 / 写草稿 / 发送 / 滚动 / 切会话 / 关弹层） |

**Flow 分析画布**是 HTML 画布的 `mode="flow"` 模式——结构化思维可视化：六种节点类型（含 9 种 ECharts 图表）、三种连线模式、三大交互原语（拖拽布阵 / 锚点连线 / 右键批注）、三种布局引擎（树状 / 时间线 / 矩阵），一键导出 PNG。

**所有画布双向编辑**——AI 可以写，你也可以直接改。历史版本追踪精确记录每一次变更，随时回退。AI 的工作过程从黑箱变成可见：你不需要「相信 AI 会做对」，你看着它做。

**画布是共享工作面，不是显示器**——你在画布上的框选、拖拽、连线、批注，都会作为语义反馈回到 AI 手里：拖拽等于空间关系声明，手动连线等于关系声明，批注等于内容反馈。你在画布上做的每个动作，AI 都读得到。

**画布不是割裂的场景，而是能力的展示区。** 十一种画布对应十一种交付形态，但泰深可以在一次任务里组合任意几种——查资料在 HTML 画布、算账在数据画布、出稿在写作画布、定稿在 PPT 画布。**画布是能力的出口，不是能力的边界。** 你的复杂需求，由这些能力组合来完成。

**画布之外还有一双手**——内置浏览器是独立窗口，带完整工具栏（多标签、收藏夹、扩展、登录态导入）；泰深能给自己截图并叠加标注（框选 / 箭头 / 高亮 / 模糊 / 序号），用来复盘界面、定位问题。

## 桌面自动化

泰深可以看你的屏幕，并在你授权的范围内操作其他应用（实验性）。

三层授权彼此独立：**监控区**（能看哪一块）、**上传授权**（哪些画面可以交给模型）、**操作授权**（动作能落在哪里）。没有授权的区域，泰深既看不到也动不了。

六种动作：写草稿、发送消息、滚动、切换会话、关闭弹层、请求用户介入。多个动作可以在一次调用里串起来（滚动找到某人 → 切过去 → 写草稿）。发送属于提交类动作，默认逐次确认；未获批准时不写入任何输入。

安全护栏：每个动作都要带上它依据的那一帧画面与区域，画面或窗口几何之后变化过，动作直接被拒；画布提供紧急停止；你在目标窗口用键鼠，观察自动暂停；出站文本先过本地敏感信息扫描（私钥、凭据直接拒绝）。

入口：泰案 → 桌面画布。首次使用需选窗口、框出监控区、圈出输入框 / 列表 / 内容区并保存权限。窗口移动或缩放后区域自动跟随；按应用记住监控范围，下次直接套用。

## 分身并行

传统 AI 一次只做一件事。泰深可以把多个独立任务同时分派给多个分身——查财报的同时读行业报告、跑数据对比，各自完成后再汇总。

**每个分身可以配不同的模型。** DeepSeek 做主引擎深度推理，视觉任务交给识图模型，生图任务走生图通道，代码审计交给专职审计。你只需要说「帮我分析这几份报告」，泰深自动把任务拆给最合适的分身。

**分身是手脚，主身是大脑。** 泰深刻意划了一条界——跑腿的活（批量操作、并行搜索、大文件读取）分出去；动脑的活（内容分析、方案设计、结果验证）留主身。分身交回的报告只当线索，主身必须回头验证：跑类型检查、看 diff、抽查关键改动。

**13 个内置专业分身**：通用任务 / 代码探索 / 任务规划 / 架构设计 / 基础设施运维 / AI 工程 / 开发者布道 / 内容创作 / 视觉识别 / 图像生成 / 动态模型调度 / 批量代码修改 / 独立代码审计——外加你可以自己造新的。

**从子代理走向会话级编排（Project Sessions）。** 子代理解决的是「一件事拆成几份同时干」；再往上，泰深支持把一个大任务拆成多个**独立会话**并行推进——每一条线都是一个完整可进入的会话，有自己的上下文、文件和产出，你可以随时进去看它做了什么、就地追问、就地验收。主会话在这一层扮演编排台：为每条线指定供应商和具体模型（配置里的任意模型都可以）、指定要做的事，最后汇总结果。这不再是「一个 AI 开几个分身」，而是**多个 AI 会话在同一个目标下协同作业**。

## 外部 Agent 会话迁移

在其他 AI 工具里积累的会话，不用重开。泰深支持读取并迁移 **17+ 种外部 Agent** 的会话——Claude Code / Cowork、Codex、Cursor、ChatGPT、Gemini、Qoder、Kimi、WorkBuddy、DSH 等。

按会话 ID 或标题关键字搜索定位，即可阅读历史对话；需要时一键转正进泰深主库，直接继承续聊。迁移走独立库缓冲，不冲击主库性能。**换工具不换历史，资产跟着你走。**

## 多供应商 & 模型

**自由切换** —— 支持 DeepSeek、OpenAI、Codex、Google Gemini、Mimo 等多家供应商。推理强度、上下文窗口等参数下沉到 per-model 级别，不同模型各自微调。

**订阅额度也能用** —— Codex 订阅可开启 Fast 加速档位，会话卡片坞显示剩余额度窗口与重置时间；额度接近用尽时给一条软提示：继续推进当前任务，但别开新的长链条，先把进度写成交接。Google Gemini 订阅（Antigravity）同样可接入。

**生图能力** —— 内置生图子代理：生成的图片经真实解码与尺寸门禁后原子提交到输出目录，前端可点击全屏查看，失败与在途任务有可恢复的状态记录。

**FlexDog 动态调度** —— 会话内随时切换模型与供应商，不用重启。想用大模型深度思考一个问题，下一句切到快模型快速响应，即时生效。

**峰谷定价适配** —— 按供应商的高峰 / 低谷时段分别计价与显示，账目清楚。

## 生态：Skills 与 MCP

**Skill 技能系统** —— 兼容 [agentskills.io](https://agentskills.io) 开放标准（Claude Code、Cursor、GitHub Copilot 等 35+ 工具通用）。自建技能、从 GitHub/Gitee 搜索安装社区技能、让 AI 自主创建新技能。支持 group/subgroup 二级分组管理。

**MCP 协议** —— 支持 Streamable HTTP / SSE / stdio 三源接入，把网页搜索、浏览器控制、学术数据库、行情数据等外部能力接进来。内置五大预置：anysearch（搜索，支持匿名）、firecrawl（深度抓取）、通达信（行情数据）、codegraph（代码图谱）、chrome-devtools（浏览器控制）。内置 MCP 不挤占用户级配置——你自行配置的同名 MCP 优先。

**按需加载** —— 工具说明不再挤占提示词空间。常用的保持开启、低频的关掉；会话里需要时泰深一键启用（会话级生效，不动全局设置）。支持热加载：会话内启停，下一条消息立即生效，无需重启会话。

**插件 + 工具自主创建** —— 插件丢入即加载；AI 可根据需求自行编写新工具（TypeScript），无需你动手。

## 四层安全防线

**路径访问控制** —— AI 只能访问你指定的工作区。系统目录、磁盘根目录、用户主目录自动拦截，短文件名绕过和符号链接逃逸也能识别。

**命令执行控制** —— 三级沙箱：L1 每步审批 → L2 AI 自主审查 → L3 完全信任。致命命令直接拦截（`rm -rf /`、`shutdown` 等），命令注入和脚本内联执行在沙箱层阻断。

**网络边界控制** —— 默认开放 DeepSeek API、GitHub 等常用域名，其他域名需申请白名单。内网地址（127.x、192.168.x、10.x）自动拦截，防 SSRF 攻击。

**门控防重试** —— 同一操作被拒绝 2 次后系统自动阻止，AI 不反复纠缠。

每次文件修改自动本地备份，随时恢复。回收站系统让误删的会话、技能、子代理随时捞回，永不过期。**正因为有这四层防线，你才敢把更多权限交给 AI。**

## AI 自诊断

泰深内置分级分类的结构化日志系统。AI 可以直接查询自己的运行日志：工具调用失败 → 自动定位根因；会话异常 → 追踪完整调用链；成本异常 → 查缓存命中率找瓶颈。

从「用户帮 AI 排错」到「AI 自己排错」——你不需要懂技术、不需要翻日志。

- **跨会话记忆** —— 记住你的偏好、工作风格和常用工具，越用越懂你
- **三层宪法** —— 用自然语言给 AI 立规矩：L1 全局 / L2 项目 / L3 会话临时，按优先级合并注入
- **项目地图** —— 每个项目自动生成一张地图（目录结构 / 技术栈 / 关键入口 / 常用命令），新会话直接定位，不再重复探索
- **语音交互** —— 语音输入（STT）转文字，语音输出（TTS）朗读回复，三种模式自由切换
- **定时任务** —— 间隔 / 每日 / 每周 / Cron / 一次性五种模式，AI 可自行创建和管理；支持批量清理与预演
- **进程监控** —— 把长跑命令的输出实时推到会话，匹配到错误关键字自动告警
- **Headless CLI** —— 纯命令行运行（`--headless`），适合脚本集成与服务器场景
- **内置运行时** —— 打包版自带 Node / Python / uv，MCP 与脚本开箱即用，不依赖你本机环境
- **会话搜索** —— 自然语言跨会话全文搜索，AI 也能主动回溯历史讨论
- **文件路径可点击** —— 项目相对路径和反引号内路径自动渲染为可点击链接
- **卡片坞** —— 任务、成本、文件、上下文等卡片统一收纳，可折叠可拖拽

## 常见问题

**Q: 需要自己部署模型吗？**
不需要。泰深通过 API 连接 DeepSeek 云端模型，你只需要一个 API Key。

**Q: 泰深和「把一堆工具拼起来的 AI」有什么不同？**
工具清单只是原料。真正的差别在编排与自造：泰深能把技能、分身、外部服务、内置工具组合成一个针对当前问题的方案；现有能力不够时，它能自己写工具、自己封经验。前者是一次性的调用，后者是会积累的能力。

**Q: 我真的不用懂代码，就能让它长出能力吗？**
是的。你说「帮我封装一下这个流程」，泰深会自己写好 Skill 或 TypeScript 工具，编译注册后下次会话生效。你只需要在它拿来给你看的时候点个头。

**Q: 支持其他模型吗？**
客户端支持配置 OpenAI 兼容接口，也可接入 Codex、Google Gemini 等供应商，但仅 DeepSeek 经过完整测试。可用 FlexDog 子代理在同一会话内对比不同模型效果。

**Q: 数据安全吗？**
所有数据存储在本地（对话记录、用户画像、文件备份），不上传至泰深服务器。API Key 使用系统级加密存储（Windows DPAPI / macOS Keychain）。

**Q: 手机能用吗？**
可以。通过飞书、QQ、微信、Slack 任一 IM 接入后，手机就是你的泰深终端——流式回复、文件传输、审批弹窗全部打通。

**Q: Skill 和 MCP 有什么区别？**
Skill = AI 的工作模式（「怎么想」），一份 Markdown 文件激活后改变 AI 的行为风格。MCP = AI 的外部工具（「用什么」），给 AI 接入网页搜索、浏览器等能力。两者可以叠加使用。

**Q: Windows 数据能迁移到 Mac 吗？**
可以。将 Windows 用户目录下的 `.taishen` 文件夹拷贝到 macOS 用户目录（`~/.taishen`）即可。注意 API Key 需重新配置（两平台加密方式不同）。

**Q: 子代理消耗 Token 吗？**
会。子代理的 Token 消耗会累积到会话预算中，费用统计完整透明。
